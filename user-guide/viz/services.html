    Services¶

    If several flights serve the same route, you may want to look at them together. A service groups legs with the same carrier, origin, and destination. You can read more about the underlying data in Services.

    Duo Comparison: Service Shifts¶

    This chart shows load factors and local shares by service, and how that changes between two runs. A line runs from the baseline result to the treatment result, which is marked by a point. Larger points represent services with more capacity.

    This is a function in passengersim.contrast.duo, not a Contrast method. There is no single-run fig_service_shifts method.

    from passengersim.contrast.duo import fig_service_shifts

fig_service_shifts(baseline, alternative, coloring="change_revenue")

    This is a paired-run function, not a Contrast method or a single-run method. See the API documentation on fig_service_shifts for additional details.

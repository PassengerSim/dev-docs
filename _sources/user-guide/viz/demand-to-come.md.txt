# Demand to Come

How many passengers have yet to arrive? This chart follows the demand still to come as departure
approaches, separately for each passenger segment.

Usually, you can use the automatically collected `demand_to_come_summary` without any database
recording. For older results without that summary, the chart can use the detailed `demand_to_come`
table instead. That requires recording `demand` throughout the booking horizon and keeping the
report or its database. The [table guide](../summary-tables/demand-to-come.md) explains how to
collect it.

## Set up the Europa examples

We’ll use `europa/upe` for the single-run charts and compare it with `europa`. The first load may
run the demo; later calls reuse its cached result.

```{code-cell} ipython3
import altair as alt
import passengersim as pax

# Keep all observations available when a figure contains more than 5,000 rows.
alt.data_transformers.disable_max_rows()
summary = pax.demo_result("europa/upe")
contrast = pax.demo_result({"europa": "europa", "europa/upe": "europa/upe"})
baseline = contrast["europa"]
alternative = contrast["europa/upe"]
```

## Following the remaining demand

Use `func="mean"` to see the average remaining demand. To see how much it varies between samples,
use `"std"` for the standard deviation. You can also ask for both panels with a list.

This plotting function is available through `Contrast`, even when you only want to look at one run.
In that case, put your summary into a `Contrast` with just one entry:

```{code-cell} ipython3
from passengersim.contrast import Contrast

Contrast(**{"europa/upe": summary}).fig_demand_to_come(func="mean")
```

```{code-cell} ipython3
contrast.fig_demand_to_come(func=["mean", "std"])
```

For a single statistic, `raw_df=True` returns the assembled data and `also_df=True` returns a
chart/data pair. With a list of statistics, `raw_df=True` is not implemented and `also_df` does not
return a data pair; request each statistic separately for its data. Use `title` to override the
heading. Comparisons use source labels to distinguish runs.

API: [`fig_demand_to_come`](passengersim.contrast.fig_demand_to_come).

# Carrier Histories

Average revenue tells us part of the story. These charts let us look at the variation from one
simulation sample to the next, and see whether good results for one carrier tend to coincide with
good results for another.

You can read about the underlying data and how to collect it in
[Carrier Histories](../summary-tables/carrier-history.md).

The setup below loads both demo results. We’ll use their actual carrier names and airport codes, so
you can run these examples without substituting your own data.

Both figures use `carrier_history2`, which is collected directly without database recording. Neither
has a dedicated `Contrast` equivalent.

## Set up the Europa examples

We’ll use `europa/upe` for the single-run charts and compare it with `europa`. The first load may
run the demo; later calls reuse its cached result.

```{code-cell} ipython3
import altair as alt
import passengersim as pax

# Keep all observations available when a figure contains more than 5,000 rows.
alt.data_transformers.disable_max_rows()
summary = pax.demo_result("europa/upe")
contrast = pax.demo_result({"europa": "europa", "europa/upe": "europa/upe"})
baseline = contrast["europa"]
alternative = contrast["europa/upe"]
```

## How much does revenue vary?

This chart shows a smoothed distribution of revenue for each carrier. A wider shape means revenue
varies more from sample to sample; a narrow shape means the results are more consistent.

Uses `carrier_history2`, collected without a database. `raw_df=True` is not implemented and raises
`NotImplementedError`; `also_df` is ignored. Read `summary.carrier_history2` directly for the
underlying observations.

For one run, call
[fig_carrier_revenue_distribution](passengersim.summaries.SimulationTables.fig_carrier_revenue_distribution):

```{code-cell} ipython3
summary.fig_carrier_revenue_distribution()
```

To compare scenarios, make this chart once for each result. There isn’t a combined comparison method
for this figure.

## Comparing two carriers within a run

Each point pairs the revenues of two carriers from the same simulation sample. This lets you see
whether the carriers tend to do well together, or whether a good result for one often comes with a
weaker result for the other.

Choose `x_carrier` and `y_carrier`. With `mean_adjusted=True` (default), each axis is relative to
that carrier’s mean; set it to `False` for revenue in currency units. This compares carriers, not
simulation runs.

For one run, call
[fig_carrier_head_to_head_revenue](passengersim.summaries.SimulationTables.fig_carrier_head_to_head_revenue):

```{code-cell} ipython3
summary.fig_carrier_head_to_head_revenue(x_carrier="Tapas", y_carrier="Stroop")
```

To compare scenarios, make this chart once for each result. There isn’t a combined comparison method
for this figure.

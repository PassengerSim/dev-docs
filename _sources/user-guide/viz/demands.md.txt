# Demands

Before interpreting sales, it helps to understand the demand you gave the simulation. This chart
lets you compare passenger segments across markets—for example, to see which markets have more
business demand and which have more leisure demand.

You can read about the underlying data and how to collect it in
[Demands](../summary-tables/demands.md).

The setup below loads both demo results. We’ll use their actual carrier names and airport codes, so
you can run these examples without substituting your own data.

## Set up the Europa examples

We’ll use `europa/upe` for the single-run charts and compare it with `europa`. The first load may
run the demo; later calls reuse its cached result.

```{code-cell} ipython3
import altair as alt
import passengersim as pax

# Keep all observations available when a figure contains more than 5,000 rows.
alt.data_transformers.disable_max_rows()
summary = pax.demo_result("europa/upe")
contrast = pax.demo_result({"europa": "europa", "europa/upe": "europa/upe"})
baseline = contrast["europa"]
alternative = contrast["europa/upe"]
```

## Comparing demand between passenger segments

Each point represents an origin–destination market. The axes show demand for different passenger
segments, making it easier to spot markets with a different mix of passengers.

The values come from the `base_demand` you configured, so this helps you review the network’s demand
inputs rather than the random demand realized in individual samples. You can choose segment names
with `x` and `y`. If you leave them out, the chart uses the first segment on the horizontal axis and
either the second segment or total demand on the vertical axis.

For one run, call
[fig_demand_segmentation_distribution](passengersim.summaries.SimulationTables.fig_demand_segmentation_distribution):

```{code-cell} ipython3
summary.fig_demand_segmentation_distribution()
```

To compare scenarios, make this chart once for each result. There isn’t a combined comparison method
for this figure.

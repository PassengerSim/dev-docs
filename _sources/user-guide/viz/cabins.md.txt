# Cabins

An aircraft can be nearly full in one cabin and have plenty of empty seats in another. Looking at
cabins separately helps you see differences that disappear in the carrier-wide average.

You can read about the underlying data and how to collect it in
[Cabins](../summary-tables/cabins.md).

The setup below loads both demo results. We’ll use their actual carrier names and airport codes, so
you can run these examples without substituting your own data.

## Set up the Europa examples

We’ll use `europa/upe` for the single-run charts and compare it with `europa`. The first load may
run the demo; later calls reuse its cached result.

```{code-cell} ipython3
import altair as alt
import passengersim as pax

# Keep all observations available when a figure contains more than 5,000 rows.
alt.data_transformers.disable_max_rows()
summary = pax.demo_result("europa/upe")
contrast = pax.demo_result({"europa": "europa", "europa/upe": "europa/upe"})
baseline = contrast["europa"]
alternative = contrast["europa/upe"]
```

## How full is each cabin?

The Europa demos have one cabin, `Y`, so this example produces a single cabin panel. With a
multicabin network, the same method adds a panel for each cabin in your results.

This chart shows load factors for each carrier and cabin. It is useful when you want to check
whether one cabin is filling up while another still has room.

Uses `cabins`; `raw_df=True` returns the plotted data. There is no dedicated contrast function.

For one run, call
[fig_cabin_load_factors](passengersim.summaries.SimulationTables.fig_cabin_load_factors):

```{code-cell} ipython3
summary.fig_cabin_load_factors()
```

To compare scenarios, make this chart once for each result. There isn’t a combined comparison method
for this figure.

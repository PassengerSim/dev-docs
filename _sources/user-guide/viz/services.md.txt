# Services

If several flights serve the same route, you may want to look at them together. A service groups
legs with the same carrier, origin, and destination. You can read more about the underlying data in
[Services](../summary-tables/services.md).

```{code-cell} ipython3
---
tags: [remove-cell]
---
import altair as alt
import passengersim as pax

# Keep all observations available when a figure contains more than 5,000 rows.
alt.data_transformers.disable_max_rows()
summary = pax.demo_result("europa/upe")
contrast = pax.demo_result({"europa": "europa", "europa/upe": "europa/upe"})
baseline = contrast["europa"]
alternative = contrast["europa/upe"]
```

## Duo Comparison: Service Shifts

This chart shows load factors and local shares by service, and how that changes between two runs. A
line runs from the baseline result to the treatment result, which is marked by a point. Larger
points represent services with more capacity.

To compare two runs, call [`fig_service_shifts`](passengersim.contrast.duo.fig_service_shifts) with
two [`SimulationTables`](passengersim.summaries.SimulationTables) objects: the baseline first,
followed by the treatment. This is a standalone function, so import it before calling it:

```{code-cell} ipython3
from passengersim.contrast.duo import fig_service_shifts

fig_service_shifts(baseline, alternative, coloring="change_revenue")
```

This function compares exactly two results. It is not a method on a
[`Contrast`](passengersim.contrast.Contrast) object and has no single-run equivalent.
